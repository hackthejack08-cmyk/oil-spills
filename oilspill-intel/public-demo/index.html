    Method and limitations
    1. Segments suspected dark formations from georeferenced Sentinel-1 SAR.
    2. Measures slick geometry and reconstructs possible origins using currents and wind.
    3. Rebuilds historical AIS tracks and filters vessels by time and location.
    4. Ranks evidence matches and exports an auditable record for analyst review.

    Attribution is a decision-support result and requires analyst review.

    Advanced / manual workflow

    The sample uses synthetic scene, forcing and AIS data. Operational use requires approved historical AIS access.

    Land polygon file is missing. Coastal masking and particle beaching must not be treated as verified in this installation.
